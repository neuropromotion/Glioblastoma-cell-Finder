Напомню что у нас есть 22 признака для каждого наблюдения. Все наблюдения гипотетически разделимы на два больших класса. Напомню также что у целевого класса будет наблюдаться нарушение в распределении значений между этими признаками, наиболее сильное из которых усиление выражения 7 признака и ослабление 10. После множества попыток получить два распределения отображая 22 признака я сошелся на том что можно ограничиться рассмотрением только 7/10 как наиболее устойчивых предикторов (с точки зрения поставки задачи, распределение в этих признаках биологически обязано быть нарушенным). Я взял 7/10 и посчитал долю выражения каждого из этих двух признаков относительно их суммы - таким образом нивелируется батч-эффект, то есть технический шум между образцами). Далее в качестве одномерного признака Берется дельта 7-10, то есть разница между выражением 7 и 10 признаков. У здоровых клеток (класс 0), разницы не должно быть, по этому распределение таких наблюдений будет иметь матожидание 0, а вот у раковых смещено вправо по вышеописанным причинам. Такой признак дает стабильно два распределения и масштабируется за пределы одного эксперимента, так что объединение нескольких экспериментов дают похожую картину.

Также я нашел образцы с экспериментами нормального мозга без рака (взяты post mortem). Такие наблюдения, при использовании в качестве признака дельту 7-10 порождают одно распределение с матожиданием у нуля - гипотеза подтвердилась. Так что у нас есть референс наблюдений класса 0

В outpos я скинул 3 датасета c уже готовым распределением признака дельта 7-10: 

1) cancer_1 - объединение 8 экспериментов с раком мозга, 7 из одной серии экспериментов и один из другой. Тут примерно 30 тысяч наблюдений, поровну класс 0/1 

2) cancer_2 - объединение 10 образцов рака мозга из одной серии образцов. Тут из 70 тысяч наблюдений, около 60 раковых, так что распределение выглядит как большой пик класса 1 и маленький класса 0

3) healthy_reference - референс здоровых клеток, 13 к. Одно распределение класса 0. Если что можно и больше
